# Image sources and attribution

Every file in this directory, where it came from, and under what licence.

**Why this file exists.** These are licensed third-party photographs, not our
own. A repository that contains someone else's images without recording their
provenance is a licence problem waiting to be discovered by whoever inherits
it — and Freepik's free licence requires attribution.

**These are placeholders.** They are category-level editorial imagery chosen
to represent what a department sells. They are not photographs of OfficeLand
stock, and every one should be replaced with the company's own photography
before launch. Replacing a file and re-running `media:import` is the whole
procedure — the filename is what binds an image to its category.

## Attribution

Freepik's free licence requires visible credit. It is **not yet placed on the
site** — that needs a decision about where it lives (a credits page, or a line
in the footer), and it must be settled before this goes public. Tracked in
BACKLOG.md.

If these are replaced with OfficeLand's own photography the requirement
disappears with them, which is another argument for doing that.

## The sidecars

Each `.txt` holds the alt text for the image beside it. It is written by hand,
because §12.6 makes alt text mandatory and a generated one describes the image
rather than its purpose on the page.
